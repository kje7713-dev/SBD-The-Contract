# SBD-The-Contract

Gaming App built with Unity 2022.3.25f1

## Unity License Activation

This project uses Unity and requires proper license activation for CI/CD workflows. 

**📋 For detailed instructions, see [Unity Activation Guide](.github/UNITY_ACTIVATION.md)**

### Quick Start

1. Navigate to the **Actions** tab
2. Run the "Unity Activation (Generate ALF)" workflow
3. Follow the instructions in the [Activation Guide](.github/UNITY_ACTIVATION.md)

## Development

- **Unity Version**: 2022.3.25f1
- **Build System**: GitHub Actions with GameCI
